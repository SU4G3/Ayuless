# Changelog

## Ayuless 1.0.0 — 2026-11-17

*Telegram 13.2.1 (72919) • Android 6.0+*

🇷🇺 **Что нового**

> - UnifiedPush: уведомления через ntfy и другие дистрибьюторы.
> - Эмодзи Noto, включая все сочетания тонов рук.
> - Нативные библиотеки и WidgetJS собираются из исходников.
>
> ⚠️ Новая подпись: нужна переустановка. Сначала экспортируйте локальную базу и вложения. Секретные чаты при удалении потеряются.

🇬🇧 **What's new**

> - UnifiedPush notifications via ntfy and other distributors.
> - Noto emoji with all handshake skin-tone combinations.
> - Native libraries and WidgetJS built from source.
>
> ⚠️ New signing key: reinstall required. Export your local database and attachments first. Secret chats are lost on uninstall.
