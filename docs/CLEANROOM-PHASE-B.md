## Проверки

- `Tools/test_ayugram_settings.py`: 139 утверждений на JVM с граничными заглушками. Включает профили, явные false, блокировки, старые сочетания параметров, категории, ботов и неизменность исходных коллекций при фильтрации снимка. Сериализация в этом тесте заменена граничной заглушкой.
- `Tools/test_cleanroom_runtime.py`: 87 утверждений на JVM с управляемыми очередями и заглушками платформы. Используются рабочие классы или извлечённые рабочие методы: чтение после успеха, разовые разрешения, секретные квитанции, офлайн, расписание, Unicode-цитаты и независимые entities, собственные Premium-проверки, обновление активных аккаунтов, признаки ограничений пересылки, медиа-переходы редакций.
- `Tools/test_strings_build.py`: пройдены проверки XML/manifest и существующие проверки загрузки строк, branding и форматирования.
- `Tools/CheckCleanroomJava.java`: успешно разобраны 74 Java-файла через парсер JDK 21. Это проверка синтаксиса, без разрешения Android-типов.
- XML обеих локалей разбирается, дубликатов имён нет, восстановленные 40 ключей присутствуют в обеих локалях, нумерованные параметры согласованы. Единственный общий ключ без RU-дубля — существующий непереводимый AyulessLauncherName.

Генерируемые тестовые файлы находятся только внутри рабочего каталога и автоматически удаляются.

```sh

JVM-тесты и парсер не заменяют эти проверки. Обязательные функции контракта реализованы; неиспользуемый необязательный текстовый диалог намеренно опущен.
